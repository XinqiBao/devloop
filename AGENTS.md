# Maintaining devloop

- Read [README.md](README.md), [PRACTICES.md](PRACTICES.md), and [ADOPT.md](ADOPT.md) as relevant before changing this repository.
- Keep tracked instructions and documentation concise, in English, and consistent with the repository's reference-only purpose.

- Check links, references, the final diff, and any affected behavior before claiming completion. Do not promote local or private context into public truth.
